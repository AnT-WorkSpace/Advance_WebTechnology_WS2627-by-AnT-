## 📚 Course Roadmap & Topics

Here is an overview of the modules covered in this course:

1. **Client-Side Technology Stack**
   * HTML5, CSS3, and JavaScript fundamentals
   * Modern client-side development tools, build tools, and package managers
2. **Software Architectures for Web Applications**
   * Server-side page generation vs. SPA architecture
   * REST server integration & Server-Side Components
3. **TypeScript**
   * Introduction to TypeScript and typed JavaScript
   * Syntax, types, interfaces, and object-oriented classes
4. **REST APIs**
   * Principles of RESTful architecture
   * Designing and implementing REST APIs with Node.js
5. **Building Web Applications with Angular**
   * Angular CLI setup and framework fundamentals
   * Single Page Applications (SPAs), components, services, and routing
6. **React**
   * Component-based architecture
   * State management, props, React Hooks, and Context API
7. **Next.js & Modern Web Frameworks**
   * Server-Side Rendering (SSR) and Static Site Generation (SSG)
   * File-based routing and full-stack React applications
8. **Containerizing Apps with Docker**
   * Introduction to Docker containers in modern web development
   * Multi-container setups using Docker Compose
